# 칩 베팅

실물 칩 없이 모여서 텍사스 홀덤이나 섯다를 칠 때, 각자 휴대폰으로 베팅하는 웹사이트입니다. 카드는 실물을 쓰고, 앱은 칩과 베팅만 관리합니다.

**사용 주소:** https://leedohyang15-design.github.io/Chip-betting-system/

## 사용법

1. 노트북이나 태블릿에서 사이트를 열고 **새 테이블 열기**를 누릅니다. 이 화면이 관리자 테이블입니다.
2. 각자 휴대폰으로 테이블의 QR을 찍거나 방 코드 4자리를 입력하고 이름을 넣습니다.
3. 관리자가 **첫 판 시작**을 누르면 차례인 사람의 휴대폰에 버튼이 켜지고 진동이 울립니다.
4. 쇼다운이 되면 관리자가 팟별로 승자를 누릅니다. 여러 명을 누르면 나눠 가집니다.

관리자 화면은 휴대폰 하나로도 운영할 수 있습니다. 함께 치려면 테이블 화면에서 **나도 앉기**를 누르세요. 내 차례가 되면 같은 화면에 베팅 버튼이 나타납니다.

### 관리자 기능

- **되돌리기**: 잘못 누른 액션과 지급을 취소
- **대신 입력하기**: 휴대폰이 꺼진 사람의 액션을 대신 입력
- **좌석 누르기**: 리바이, 칩 수정, 다른 사람에게 칩 이동(땡값 등), 자리비움, 내보내기
- **정산**: 바이인 대비 손익, 먼저 나간 사람 포함
- **판 취소**: 이번 판에 낸 칩을 모두 돌려줌
- **링크 공유**: 대기 화면에서 참가 링크를 메신저로 보냄

## 규칙

| | 텍사스 홀덤 | 섯다 |
|---|---|---|
| 시작 | 스몰/빅 블라인드, 선택적 앤티 | 앤티, 직전 승자가 선 |
| 베팅 | 프리플랍, 플랍, 턴, 리버 | 2장 받고 1번 (설정에서 한 장씩 2번으로 변경) |
| 액션 | 체크, 콜, 벳, 레이즈, 폴드 | 체크, 콜, 삥, 따당, 쿼터, 하프, 풀, 다이, 올인 |

- 하프, 쿼터, 풀은 콜한 뒤의 판돈을 기준으로 앤티 단위로 올림해 계산합니다.
- 따당은 콜 금액의 두 배를 냅니다.
- 올인이 나오면 사이드 팟을 자동으로 나누고, 콜되지 않은 금액은 돌려줍니다.
- 섯다 재경기는 판돈을 유지한 채 관리자가 고른 사람만 앤티 없이 다시 칩니다.

## 구조

GitHub Pages에는 서버 코드를 둘 수 없어서, 테이블을 연 브라우저가 서버 역할을 합니다. 휴대폰과 관리자 브라우저는 가입 없이 쓸 수 있는 공개 MQTT 중계 서버(EMQX, shiftr.io, TBMQ)를 웹소켓으로 거쳐 통신하므로 와이파이와 5G가 섞여도 연결됩니다. 게임 상태의 원본은 관리자 브라우저의 localStorage에 있습니다.

관리자는 중계 서버 3곳에 동시에 접속하고, 휴대폰은 한 곳이 응답하지 않으면 다음 곳으로 넘어갑니다. 메시지는 방 코드에서 만든 키로 AES-GCM 암호화합니다.

- `js/engine.js`: 베팅 규칙 (DOM 없음, `npm test`로 검증)
- `js/net.js`: 연결과 자동 복구
- `js/dock.js`: 베팅 버튼과 레이즈 시트
- `js/fx.js`: 칩 연출과 효과음
- `js/host.js`, `js/player.js`, `js/home.js`: 화면
- `vendor/`: MQTT.js 5.10.1, qrcode-generator 1.4.4

## 알아둘 점

- 관리자 화면이 꺼지거나 다른 앱으로 넘어가면 테이블이 멈춥니다. 화면으로 돌아오거나 같은 기기에서 다시 열면 이어서 진행되고 휴대폰은 자동으로 재접속합니다.
- 소리는 화면을 한 번 터치한 뒤부터 납니다. 아이폰은 진동을 지원하지 않아 소리와 화면 번쩍임으로 차례를 알립니다.
- 공개 중계 서버는 테스트용으로 운영되는 무료 서비스라 가동을 보장하지 않습니다. 세 곳이 모두 막히면 접속할 수 없습니다.
- 암호화 키가 4자리 방 코드에서 만들어지므로 지나가는 도청은 막지만 작정한 공격까지 막지는 못합니다. 칩 현황과 이름 외의 민감한 정보를 다루지 않습니다.
- 방 코드를 아는 사람은 누구나 입장할 수 있습니다. 모르는 사람이 들어오면 좌석을 눌러 내보내세요.
